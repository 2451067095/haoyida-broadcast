# 合规与原创性说明

本文记录“功能对标”的边界，供内部评审与必要的法务沟通使用。

## 1. 只做了功能层面的研究

对参考软件安装包（`mallmaster1620-9621-setup.exe`）做的是**静态结构分析**，没有运行它，也没有复用其中任何内容：

1. 解析 PE 头：资源段里是一份 OLE 复合文档。
2. 从复合文档取出内嵌 CAB，用 Windows 自带 `expand` 列出 160 个文件。
3. 由此得到的只是**模块构成**：Qt 主程序、VLC、ffmpeg、SQLite 客户端库、阿里巴巴普惠体、示例 BGM、示例音乐。
4. 主程序是 Qt 编译产物，中文界面文本被压缩进资源，未能提取——**也没有继续破解**。

**据此提炼的是产品能力清单**（定时播报、循环轮播、商品促销、背景音乐、语音合成），属于思想/功能层面。

## 2. 明确没有使用的部分

- ❌ 反编译或阅读其源代码
- ❌ 复制其界面布局文件、图标、图片
- ❌ 使用其随包的**阿里巴巴普惠体**字体
- ❌ 使用其随包的 `good_morning.mp3` / `good_evening.mp3` 等音频
- ❌ 复用其数据库表结构或配置格式
- ❌ 使用 `mallmaster` 名称、Logo 或任何商标元素

本项目的界面按 [Dashboard 设计规范](design-system.md) 独立设计；所有 XAML、C#、配色、图标（纯 Path 几何）均为新写。

## 3. 第三方组件的许可义务

| 组件 | 许可 | 义务 |

| Piper（代码 + `zh_CN-huayan-medium` 音色） | MIT | 分发时附带 MIT 许可证与版权声明 |

## 4. 功能与表达的区别

著作权保护的是**表达**（代码、界面美术、文案、音频），不保护**思想与功能**。“超市定时播报”这一功能人人可做。
因此本项目：

- 功能清单可以相同；
- 代码、界面、文案必须不同——本项目全部重写；
- 不宣称与参考软件存在任何关联或授权关系。

## 5. 商标与名称

`耗易达` 为委托方提供的产品名。发行前请自行完成商标检索（第 9 类：计算机软件）。
参考软件的名称、图标、界面标识一律未使用。

## 6. 数据与隐私

- 所有配置保存在本机 `%LOCALAPPDATA%\Haoyida`，不上传。
- 在线引擎（edge-tts）会把**播报文本**发送到微软服务；需在门店告知中说明，或直接禁用该引擎。
- 语音克隆类模型（如 GPT-SoVITS）涉及**声音权/人格权**，必须取得被克隆人书面授权。

## 7. 发布前建议

1. 法务复核本文与 `docs/tts-open-source.md`；
2. 在“关于”页补齐第三方许可全文；
3. 保留本文作为“独立实现”的过程证据（含解包时间线与文件清单）；
4. 如仍有顾虑，可请第三方做代码相似度比对（本项目无参考软件代码，比对结果应为零命中）。
